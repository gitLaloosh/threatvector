Mockups no longer served on the site

Tools 2026-11-09 · page unchanged (after v2026.11.08.4)

Why

  • Since build queue 027 the site is everything tools/publish.py copies from the repo: every tracked file. That included the 45 mockups in Claude outputs/ (about 40 MB), so each was a live page on threatvector.space.
  • A mockup is a copy of the page with made-up data and stand-in logins. On the same site it shares the real page's browser storage, so opening one could read or overwrite a visitor's Intel settings, Standings or My Fits, and it could be taken for the real page.
  • Found while the owner asked whether prototypes should go into the repo at all; the owner: "i'd like you to just take care of it".

What changed (tools only)

  • publish.py skips Claude outputs/ (NOT_SERVED). The files stay in the repo; the next publish leaves them out, and GitHub Pages serves only what the publish step uploads, so they stop being reachable.
  • Its self-test fails if anything under Claude outputs/ would be served (checked by removing the skip: caught).
  • Prototypes for new items stay in the Project as their build scripts (the owner's choice for 028 and 029).

Checks

  • The publish self-test: 0 problems. A publish to a scratch folder: 525 files, none from Claude outputs/ (every other tracked file still copied).
  • The fast lints and the served-copy checks.
