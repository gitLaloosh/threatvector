publish.py --size

Tools 2026-11-08 · page unchanged (after v2026.11.08.3)

  • Why: a planning session's review of its start-up doc found that getting the served page size meant publish.py --out, which copies the whole site (560+ files, about 62 MB) to report one number.
  • What: python3 -I tools/publish.py --size makes the served copy of index.html in memory, runs the same checks on it, and prints both gzipped sizes. Nothing is written. It exits 1 past the 800,000-byte ceiling. CLAUDE.md step 6 and the tools README name it.
  • Checks: the publish self-test (0 problems), the fast lints, and --size by hand: 791,679 source, 493,696 served, about 5 s.
