Region names where system names are shown; the hidden fleet view and Against Your Ship taken out

Page 2026-11-12 · v2026.11.12.2 · build queue 038 · plan: Project doc roadmap/region-names-plan.md · mockup: Claude outputs/region_names_mockup.html

Why

  • The owner, 2026-11-11: "widen it to do a review of existing places where system name is used and show me the list. i'll tell you where i would like to add the region name." He picked 12 of the 27 places, and "we dont need region names for wormhole space".
  • From the mockup: Near You and the Feed "A: own column" (Near You changed at the build, below); the Fleet tab's and the dossier's kill lists on phones "System only"; sentences "Yes, as drawn" ("E-VKJV (Querious)", "8-YNBE (Querious, 4 jumps)").
  • The removal: "have it removed with the next change to the system analyzer tab" (the fleet view had been off since v.89, Against Your Ship since v2026.10.31.1).

What changed

  • sysRegion(id): a system's region from the map's table already in the page (INTEL_MAP.reg / .regions), only the region bytes unpacked, once. Nothing for a system the table doesn't cover (wormholes, Jove space) or while the map table doesn't match the jump table. sysBracket(id, jumps) writes every sentence's bracket, so they can't drift apart.
  • The Feed: a Region column after the system, as wide as the widest region name measured in the cell's font (--it-rg-w in itSysWidths; the Intel example sizes it to its own widest); plain dim text with no hover; hidden under 600 px.
  • Near You: the region on a line under the system name (the owner at the build, "Under the system"). Near You sits about 400 px wide beside the map between 905 and 1200 px, and the Region column from the mockup left its tags no room there (they spilled over the time and off the row; intel_layout_check's busy row caught it). The line runs from the system's column to the row's end, so no region is cut short; a system with no region gets no line (:has(> .it-rg:empty)); hidden under 600 px.
  • Sentences: Intel's status line ("… in 1DQ1-A (Delve)"), the desktop notification's title ("E-VKJV (Querious) · 3 jumps"), the System Analyzer's and the Pilot Analyzer's "From Intel" notes ("8WA-Z6 (Delve, 1 jump)"), the Fleet tab's head line and the kill picker's heading. They keep the region on a phone.
  • The Feed search finds a region's reports by its name; its placeholder says "region".
  • The Pilot Dossier: each usual system with its region (dim); the kill list under a hull has a Region column after System (hidden where the list stacks, 900 px and under). The kill picker's rows have a Region column after the system (hidden under 600 px). These two columns narrow on a smaller window and show the name on hover.
  • Taken out: the fleet view (L4) and Against Your Ship (L5), their flags, branches, view code, two info panels, CSS, the name "Against Your Ship", and the checks fleet_view_check.py and vs_check.py. Kept, because live code uses them: the common-fit helpers (saHullFits and its parts: the dossier and the Fleet tab), the card classes the Fleet tab's summary and victim cards draw (.fl-sum and its parts), and fleet_vs_check.py, which checks the live Fleet tab despite its name.
  • No request, no stored data. Info text: checked; none (no panel lists the columns, the search or the hidden views).

Checks

  • New tools/page_checks/region_names_check.py: every place above, with the regions decoded by the check itself from INTEL_MAP; a wormhole shows none; the column one column and as wide as the widest region; no row's hover names its region; 390 px hides the cells and keeps the sentences; 5 mutants, all caught.
  • check_html_sinks: the baseline shrank from 1648 to 1515 (the removed code, and six changed expressions rewritten as small builders instead of being added to it).

Lesson for future models

  • LESSON #159: deleting by name deletes what the name once meant. The queue item listed fleet_vs_check.py for deletion, but it checks the live Fleet tab; the fleet view's code and CSS blocks held helpers and classes other features use. Before removing a feature, list what its block defines and search each name outside it. Also: itB64 decodes 16-bit numbers, so a one-byte table needs its own decode.
  • LESSON #113 again: the mockup was checked at 1440 and 390 px only. Near You's narrowest width (about 400 px beside the map, windows of 905 to 1200 px) is where the Region column broke the busy row. A plan that adds a column to a list should name that list's narrowest width and check a busy row there.
