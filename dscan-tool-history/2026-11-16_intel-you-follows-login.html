Intel's You follows your EVE login while Use my game location is on

IntelSSO 2026-11-16 · v2026.11.16.2 · build queue 054 · plan roadmap/intel-you-follows-login-plan.md (no mockup, the owner's choice)

Why

The owner, 2026-11-12: "currently if i log into the tool and turn on "use my game location", should we disable the radio buttons in intel settings for who to track? i noticed some weird behavior with this the other day". Three things were wrong: picking another character than the login quietly stopped the game location (only an amber line said so); changing the pick kept the last game answer, so switching back could reuse an old system for a moment; and a logged-in character with no Local log in the folder couldn't be picked, so the game location never applied to it. His decisions: "when logged in and use my location is turned on, use the same style and message as in the eve tab ... only see radio buttons when you're not logged in w/ use my location enabled", "only the light and status line", and the "Game location" line goes. At the build review he took all four of the build session's proposals: one itMeSync(), the "No Local log" line only once the folder is read, the EVE wording of the "system isn't known yet" warning for a character with no Local log, and "the status line" in the info text.

What changed

  • Who You is: while the switch is on and you're logged in (or the login ended and its pilot is kept), You is the login's character (itFollowLogin, itMeResolve): its Local log when the folder has one, else a stand-in whose system comes from EVE alone. The radio pick is never changed; it's back on Log out or with the switch off. Your own channel logs are preferred for that character.
  • One place decides it: itMeSync(), from renderSidePanel (every login change ends there, a reload's restored login and a copied tab's drop too) and the end of itScan (a Local log appearing). A change resets the game's last answer, the alert memory and the next scan once; no change, nothing. The radio's own handler goes through it too, so changing the pick now drops the old game answer as well.
  • Intel settings → You: while following, no radios: the EVE tab's own row (lamp, Use my game location, its ⓘ, the status line, no switch), the location's messages with Log in again, and, for a character with no Local log, "No Local log for <name>: your system comes from EVE only" once the folder has been read. The login ended: the row stays, "Paused: log in again". The "Game location: … · Set on your profile's EVE tab" line and the "Your EVE login is X, not Y" warning are gone (Intel and the EVE tab).
  • A You with no Local log: "Your system isn't known yet (it comes from EVE once it answers)", in Intel's warning and the map's empty line; the Local log's wording otherwise.
  • Login ended: ssoLost marks the login lost before ending it, so You never flips to the pick and back in between.
  • Stored data: none changes (it.set.me and it.set.gameLoc keep their form in dscanIntel).
  • Info text: intel#game (the status line shows both; Intel follows the logged-in character); METHODOLOGY.md's Intel section.
