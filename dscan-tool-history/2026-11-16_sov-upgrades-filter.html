The Intel map's Sov upgrades filter (part 2)

Intel 2026-11-16 · v2026.11.16.1 · build queue 053 · plan roadmap/intel-layout-sov-plan.md (part 2, section 14; mockup Claude outputs/intel_layout_mockup.html)

Why

The owner, 2026-11-14: "i've got a list of sov upgrades that i'd like to be able to apply to the map like filters but i'd like to be able to pick and choose which ones". The design cycle that followed gave the Intel tab its new layout (052, part 1) and this filter (part 2): "Paste now, ESI later", "Kind, level shown", "Until replaced", "Bright / dim", "More kinds later", and lists "each on it's own so it can be replaced or edited separately". At the build review: "Yes, one shared path", "420 px, one column below", "Bright anywhere", "INTEL-11 when storage is full", "Load names before checking". The Wormholes tab's panels, first meant to ride along, were taken out to be planned on their own.

What changed

  • The table: INTEL_SOV, 44 sovereignty hub upgrades from CCP's data (the four upgrade groups, published types only), written by tools/gen_intel_tables.py as [typeId, name, kind, level].
  • The filter: Sov upgrades, before Paths to you, with its panel button beside it. The panel (the site's panel style, the shared close button, Escape, a press outside) shows the kinds your lists hold, grouped Ratting / Exploration / Navigation / Mining / Other, one checkbox each with its count of systems and, in the hover, the levels. Systems with a ticked kind stay bright anywhere on the map, past its reach too; the rest dim; yours never. The hover names a system's upgrades with their levels; the key line under the map names what's bright.
  • Lists: pasted as System <- Upgrade, Upgrade lines or as system names alone with a kind (Cyno beacons by default), each line checked as you type (✓ / ⚠ naming what isn't an upgrade / ✗), each list on its own with Edit, Replace and Remove (Undo for 6 seconds). Kept in this browser only, in a new localStorage key tvSov; never sent, exported or put in a check or the repo.
  • One filter panel at a time: 052's placement now reads whichever panel is open (itMapPanel); the Sov panel sits beside Near You only with 420 px of room, its picks in one column below about 530 px.
  • INTEL-11 (new): the browser's storage is full; the lists work for the visit. The system names load before a paste is checked (INTEL-03 when ESI can't give them).
  • Info text: Intel's [Map] and [Privacy and tabs]; METHODOLOGY.md's Intel section.
